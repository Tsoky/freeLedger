# 自由账本 Android

这是一个按照“完全自定义分类 + 月计划核销 + 支付后顺手记账”逻辑做的 Android 原生 MVP。

## 核心流程

1. 你自己创建支出分类、收入分类、账户。
2. 你自己创建每月计划，例如：
   - 房租 ¥3000
   - 日本旅行 ¥5000
   - AI 工具 ¥600
3. 计划可以绑定你创建的分类，也可以不绑定。
4. App 获得 Android 的“通知使用权”后，会在本机读取新通知。
5. 如果通知同时包含：
   - 支付相关关键词（支付 / 消费 / 扣款等，可自己修改）
   - 可识别金额（¥ / ￥ / 元）

   App 会发出一条“检测到一笔可能的支出”的通知。
6. 点击“记一笔”，金额和商家会自动预填。
7. 你确认分类、账户、月计划后保存。
8. 如果关联了月计划，计划的“已花 / 剩余 / 超支”会同步更新。
9. 同一商家保存过一次后，App 会记住上次用过的分类和账户，下次自动预选。

## 隐私设计

- 项目没有申请 `INTERNET` 权限。
- 支付通知解析在手机本机完成。
- 原始支付通知不会上传。
- 没有使用 Accessibility / 无障碍服务抓屏。
- 不读取密码、验证码或银行卡号。
- 数据保存在 App 的 SharedPreferences 中。
- 支持 JSON 导入 / 导出。

## Android 支付检测的现实限制

这个 App 监听的是 Android 系统通知，不是直接读取支付宝、微信或银行的内部交易数据。

因此只有在以下条件满足时才能自动发现支付：

- 支付 App / 银行 App 真的发出系统通知；
- 通知文字中包含金额；
- 你给“自由账本”开启了通知使用权；
- 系统没有把相关通知内容隐藏掉。

如果某次支付没有任何系统通知，App 无法凭空知道你付钱了。

## 开发环境

项目使用：

- Java 17
- Android Gradle Plugin 9.3.0
- compileSdk 36
- targetSdk 36
- minSdk 26

Android 16 使用 API 36。AGP 9.3.0 对应 Gradle 9.5.0 / JDK 17。

## 如何运行

1. 安装 Android Studio。
2. 安装 Android SDK Platform 36。
3. 用 Android Studio 打开本文件夹 `FreeLedgerAndroid`。
4. 如果 IDE 提示创建 / 更新 Gradle Wrapper，选择 Gradle 9.5.0。
5. 连接 Android 真机。
6. Run `app`。
7. 首次打开：
   - 允许通知权限；
   - 点击“开启支付检测”；
   - 在系统页面允许“自由账本”读取通知；
   - 返回 App，在“检测规则”里先点“发送一条测试支付检测”。

## JSON 迁移

Android 版的导入逻辑会识别：

- Android 版导出的 JSON；
- 之前网页版自由账本中 `{ "data": ... }` 的 JSON；
- 直接以 categories / accounts / transactions / plans 为根节点的 JSON。
