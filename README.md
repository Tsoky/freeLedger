# 自由账本 Android

这是一个把“支付后随手记账”和“预算计划执行”放在核心位置的 Android 原生记账应用。

## 核心流程

### 支付弹窗随手记

开启通知使用权后，App 会在本机监听支付通知。识别到支付金额后，会立即弹出“确认记账”通知，点击即可进入记账页面，金额和支付来源自动预填，确认分类和计划后保存。

### 预算计划

你可以按月创建多个预算计划，例如：
   - 房租 ¥3000
   - 日本旅行 ¥5000
   - AI 工具 ¥600
计划可以绑定支出分类。绑定后，只有匹配该分类或明确关联该计划的支出，才会计入对应计划的执行进度，避免其他分类误算进预算。

### 使用流程

1. 创建支出分类、收入分类和月度预算计划。
2. 开启 Android 通知使用权。
3. 支付通知同时包含以下内容时：
   - 支付相关关键词（支付 / 消费 / 扣款等，可自己修改）
   - 可识别金额（¥ / ￥ / 元）

   App 会发出一条“检测到一笔可能的支出”的通知。
4. 点击通知进入随手记页面，确认分类和预算计划后保存。
5. 预算页面会显示每个计划的已花、剩余或超支进度。

## 隐私设计

- 项目没有申请 `INTERNET` 权限。
- 支付通知解析在手机本机完成。
- 原始支付通知不会上传。
- 没有使用 Accessibility / 无障碍服务抓屏。
- 不读取密码或验证码。
- 数据保存在 App 的 SharedPreferences 中。
- 支持 JSON 导入 / 导出。

## Android 支付检测的现实限制

这个 App 监听的是 Android 系统通知，不是直接读取支付宝、微信或银行的内部交易数据。

因此只有在以下条件满足时才能自动发现支付：

- 支付 App / 银行 App 真的发出系统通知；
- 通知文字中包含金额；
- 你给“自由账本”开启了通知使用权；
- 系统没有把相关通知内容隐藏掉。

如果某次支付没有任何系统通知，App 无法凭空知道你付钱了。

## 开发环境

项目使用：

- Java 17
- Android Gradle Plugin 9.3.0
- compileSdk 36
- targetSdk 36
- minSdk 26

Android 16 使用 API 36。AGP 9.3.0 对应 Gradle 9.5.0 / JDK 17。

## 如何运行

1. 安装 Android Studio。
2. 安装 Android SDK Platform 36。
3. 用 Android Studio 打开本文件夹 `FreeLedgerAndroid`。
4. 如果 IDE 提示创建 / 更新 Gradle Wrapper，选择 Gradle 9.5.0。
5. 连接 Android 真机。
6. Run `app`。
7. 首次打开：
   - 允许通知权限；
   - 点击“开启支付检测”；
   - 在系统页面允许“自由账本”读取通知；
   - 返回 App，在“检测规则”里先点“发送一条测试支付检测”。

## JSON 迁移

Android 版的导入逻辑会识别：

- Android 版导出的 JSON；
- 之前网页版自由账本中 `{ "data": ... }` 的 JSON；
- 直接以 categories / accounts / transactions / plans 为根节点的 JSON。
